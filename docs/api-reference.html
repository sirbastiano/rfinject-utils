API reference

Core modules and helpers

Focus on practical entry points you will call in scripts and notebooks.

rfinject.utils

explore_zarr_structure(zarr_group, max_depth=3)

Prints group/tree structure and nested attributes.

access_array_data(zarr_group, burst_name, array_name)

Returns a Zarr array from one burst and data key.

get_array_slice(array, slice_params=None)

Extracts an inspection window; defaults to a 10x10 corner slice.

get_burst_info(zarr_group)

Returns dictionary metadata for burst groups including shapes and memory footprint.

access_attributes(zarr_item, path=None)

Reads attrs from root or any nested path.

explore_all_attributes(zarr_group)

Walks the hierarchy and returns all discovered attrs in dictionary form.

rfinject.viz

plot_complex_array(array, title='Complex Array Visualization', figsize=(15,5))

Plots magnitude, phase, and real components for complex arrays.

plot_magnitude(array, title='Magnitude', ...)

Visualize magnitude values with optional dB scaling, normalization, and save-to-file.

rfinject.trainer

train_model(...)

Training entry point with callbacks, checkpoints, and dataloaders.

run_inference(model_checkpoint_path, data_module)

Loads a checkpoint and runs inference using a Lightning-style data module.

setup_callbacks(checkpoint_dir='./checkpoints')

Builds model checkpoints and learning-rate monitoring callbacks.

Example call

from rfinject.utils import access_attributes, get_burst_info

burst_info = get_burst_info(zarr_data)
metadata = access_attributes(zarr_data, "burst_0/echo")
print(len(burst_info), list(metadata.keys())[:5])
